## مدیریت موجودی
برای تغییر گوشی‌های نمایش‌داده‌شده، فقط فایل `inventory.js` را باز کن. هر گوشی این مشخصات را دارد:
- `name`: مدل
- `storage`: حافظه
- `color`: رنگ
- `condition`: نو یا کارکرده
- `price`: قیمت یا «استعلام قیمت»
- `image`: مسیر عکس گوشی (اختیاری)

مثلاً می‌توانی عکس را کنار فایل‌ها با نام `iphone17.jpg` بگذاری و مقدار `image` را `"iphone17.jpg"` قرار دهی.
