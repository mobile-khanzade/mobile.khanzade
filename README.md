# Mobile Khanzade — GitHub-ready storefront

این نسخه بر اساس تصویر مرجع ساخته شده و تغییر درخواستی شما را اعمال می‌کند:

- هیچ قیمت ثابتی در کارت محصولات نمایش داده نمی‌شود.
- به‌جای قیمت، دکمه «استعلام قیمت در واتساپ» قرار دارد.
- با کلیک روی دکمه، واتساپ باز می‌شود و نام محصول + دسته‌بندی + توضیحات همان محصول از قبل داخل پیام قرار می‌گیرد.
- طراحی RTL، ریسپانسیو و مناسب GitHub Pages است.
- فایل `reference.png` فقط برای مقایسه با طرح مرجع نگه داشته شده است.

## قبل از انتشار
در فایل `script.js` این خط را پیدا کنید و شماره واتساپ واقعی فروشگاه را جایگزین کنید:

`const WHATSAPP_NUMBER = "989000000000";`

شماره را بدون `+`، فاصله یا خط تیره وارد کنید.

## اجرا
فایل `index.html` را باز کنید یا کل پوشه را داخل GitHub قرار دهید و GitHub Pages را فعال کنید.

> توجه: تصاویر محصولات موجود در این بسته از تصویر مرجع برش داده شده‌اند. برای نسخه نهایی فروشگاهی، بهتر است تصاویر اصلی هر محصول را جایگزین فایل‌های داخل `assets` کنید.
