# Khan V2ray Bot

ربات فروش کانفیگ با پرداخت کارت‌به‌کارت و تأیید دستی رسید.

## راه‌اندازی
1. در @BotFather ربات را بسازید و توکن بگیرید.
2. یوزرنیم دلخواه را در BotFather روی `KhanV2rayBot` تنظیم کنید (اگر آزاد باشد).
3. آیدی عددی ادمین تلگرام را پیدا کنید.
4. Python 3.10+ نصب کنید.
5. وابستگی‌ها را نصب کنید:
   `pip install -r requirements.txt`
6. متغیرهای محیطی را تنظیم کنید:
   - `BOT_TOKEN=توکن ربات`
   - `ADMIN_ID=آیدی عددی ادمین`
7. اجرا:
   `python bot.py`

## روند سفارش
کاربر پلن را انتخاب می‌کند → کارت‌به‌کارت → عکس رسید را می‌فرستد → رسید برای ادمین می‌آید → ادمین تأیید/رد می‌کند → پس از تأیید، ادمین کانفیگ را در پاسخ به ربات می‌فرستد → کانفیگ برای مشتری ارسال می‌شود.

شماره کارت و قیمت‌ها در `bot.py` قرار داده شده‌اند.
