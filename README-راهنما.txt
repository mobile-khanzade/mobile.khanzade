موبایل خانزاده — نسخه جدید حرفه‌ای

فایل اصلی:
- index.html

فایل‌های ظاهری و امکانات:
- assets/style.css
- assets/app.js

نکته مهم:
1) برای GitHub Pages، فایل index.html باید در ریشه Repository باشد.
2) پوشه assets را هم کنار index.html آپلود کن.
3) محصولات در assets/app.js داخل آرایه products هستند. برای اضافه کردن گوشی جدید فقط یک آیتم مشابه بساز.
4) عکس هر محصول در فیلد image است و می‌توانی URL عکس خودت را جایگزین کنی.
5) شماره واتساپ در index.html و app.js قرار دارد؛ اگر شماره عوض شد، همان‌جا تغییر بده.
6) آدرس فروشگاه و آیدی اینستاگرام در index.html قابل تغییر است.

طراحی این نسخه عمداً کاملاً متفاوت از سایت قبلی است: زمینه روشن، سرمه‌ای عمیق، نارنجی مدرن، کارت‌های مینیمال، هدر شیشه‌ای، نمایش محصول، فیلتر برند و فرم واتساپ.
