برای تغییر عکس‌های محصولات:
فایل عکس جدید را داخل پوشه assets آپلود کن و در index.html فقط مسیر src همان کارت را عوض کن.
مثلاً:
assets/phone-iphone.svg  ->  assets/iphone-13.jpg

برای تغییر شماره واتساپ:
عبارت 989925457503 را در index.html جستجو و با شماره جدید جایگزین کن.

برای تغییر متن‌ها:
متن‌های داخل index.html مستقیماً قابل ویرایش هستند.

این نسخه بدون کتابخانه جاوااسکریپت خارجی ساخته شده و روی GitHub Pages قابل اجراست.
